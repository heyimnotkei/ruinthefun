# Ruin the Fun

Ruin the Fun is a Vintage Story client mod that puts optional convenience features behind a settings menu and hotkeys.

Features include saved homes, a movement speed control, one-hit blocks, no-fall, flight, fast place, configurable hotkeys, a hotkey overlay, and localized help/settings.

## Build

Requires .NET 8 and the Vintage Story client/API assemblies. Build with:

```powershell
dotnet build .\RuinTheFun.csproj /p:VSGamePath="C:\Program Files\Vintagestory"
```

The mod targets Vintage Story 1.22.2.
